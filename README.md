Программно-аппаратный комплекс для двухколесного самобалансирующегося робота на базе контроллера стабилизации подвесов **BGC 1.3 (ATmega328P)** и инерциального датчика **MPU6050**.

Проект включает:
1. **Оптимизированную прошивку микроконтроллера (`.ino`)** с циклом опроса IMU **1000 Гц**, аппаратной фильтрацией вибраций и ПИД-регулятором баланса с защитой от насыщения.
2. **Автономный веб-осциллограф, COM-терминал и симулятор физики на Python (`read_com_live3.py`)** для настройки коэффициентов в реальном времени без зависимостей от `matplotlib` и внешних CDN.

## ⚙️ Аппаратная часть и распиновка (BGC 1.3)

| Компонент | Интерфейс / Пины BGC 1.3 | Примечание |
| :--- | :--- | :--- |
| **Микроконтроллер** | ATmega328P (16 МГц, 5 В) | Плата: *Arduino Pro or Pro Mini (5V, 16MHz)* |
| **IMU MPU6050** | `SDA -> A4`, `SCL -> A5` | Шина I2C в режиме Fast Mode (`400 кГц`), адрес `0x68` |
| **Левый мотор BLDC** | ШИМ `3, 5, 6` | Векторное управление (SimpleFOC), 7 пар полюсов |
| **Правый мотор BLDC** | ШИМ `9, 10, 11` | Векторное управление (SimpleFOC), 7 пар полюсов |
| **Магнитные энкодеры** | Аналоговые `A0` (L), `A1` (R) | Датчики AS5600 в аналоговом режиме |
| **Питание / Связь** | 3S LiPo (`12.0 В`) / UART `115200` | Программный лимит напряжения моторов `±9.6 В` |

### Ключевые оптимизации прошивки
* **Пакетное чтение I2C (Burst Read):** 14 байт регистров (`0x3B`–`0x48`) считываются за одну транзакцию, что сокращает время блокировки цикла в ~2.5 раза.
* **Аппаратный фильтр нижних частот (DLPF):** Запись `0x03` в регистр `CONFIG (0x1A)` подавляет вибрации от роторов на частоте выше **44 Гц**.
* **Динамический шаг интегрирования (`dt`):** Расчет фактического интервала между итерациями через `micros()` предотвращает «уплывание» угла при колебаниях нагрузки на процессор.
* **Мгновенный старт:** После калибровки дрейфа гироскопа (1024 отсчета) начальный угол приравнивается к углу акселерометра (`robot_angle = Acc_angle`).

## 🚀 Установка и запуск (PyCharm / Терминал)

### 1. Подготовка окружения Python
Установите минимально необходимые пакеты для работы с последовательным портом и консольным вводом:

```bash
pip install pyserial prompt_toolkit
```

> **Примечание для PyCharm:** Чтобы корректно работала интерактивная строка ввода `>` (`prompt_toolkit`), в настройках конфигурации запуска (*Run -> Edit Configurations*) включите опцию **`Emulate terminal in output console`**.

### 2. Режим 1: Виртуальная симуляция ПИД-регулятора (без платы)
Позволяет подобрать коэффициенты `Kp`, `Ki`, `Kd` с учетом реальных шумов MPU6050 и ограничения питания `±9.6 В`:

```bash
python3 tools/read_com_live3.py --sim
```

### 3. Режим 2: Работа с реальной платой BGC 1.3
Укажите ваш последовательный порт (на macOS — `/dev/tty.usbserial-*`, на Windows — `COM3`):

```bash
python3 tools/read_com_live3.py -p /dev/tty.usbserial-588F0264801 -b 115200
```

После запуска откройте в браузере локальный веб-осциллограф:  
👉 **`http://127.0.0.1:8000`** *(порт можно изменить флагом `-w 8001`)*.

## 🎮 Интерактивные команды в консоли (`>`)

Во время работы скрипта вы можете менять настройки на лету прямо из терминала, наблюдая реакцию кривых в браузере:

| Команда | Пример | Описание | Режим |
| :--- | :--- | :--- | :--- |
| `p<val>` / `kp<val>` | `p2.1` или `kp2.1` | Изменить пропорциональный коэффициент `Kp` | Плата / Симуляция |
| `i<val>` / `ki<val>` | `i9.0` или `ki9.0` | Изменить интегральный коэффициент `Ki` | Плата / Симуляция |
| `d<val>` / `kd<val>` | `d0.12` или `kd0.12` | Изменить дифференциальный коэффициент `Kd` | Плата / Симуляция |
| `g<val>` | `g0.996` | Изменить вес гироскопа в комплементарном фильтре (`0.0..1.0`) | Плата / Симуляция |
| `kick` | `kick` | Подать внешний импульс толчка на корпус робота | Только `--sim` |
| `reset` | `reset` | Сбросить виртуального робота в начальный наклон `15°` | Только `--sim` |
| `exit` | `exit` | Закрыть COM-порт, сохранить `com_debug.log` и выйти | Все режимы |

## 📊 Интерпретация графиков веб-осциллографа

* 🟠 **Оранжевая линия (`Acc_angle`):** Сырой угол по акселерометру (чувствителен к тряске и линейным ускорениям).
* 🔵 **Синяя линия (`robot_angle`):** Итоговый отфильтрованный угол наклона корпуса (1 деление сетки = `30°`).
* 🟢 **Зеленая линия (`gyroY`):** Угловая скорость тангажа по гироскопу (`°/с`).
* 🟣 **Фиолетовая линия (`PID`):** Выходное управляющее напряжение регулятора на моторы (масштаб `1 В = 10 px`, лимит `±9.6 В`).

## 🛡️ Безопасность при первом запуске на железе
1. При подаче питания регулятор заблокирован (`PID = 0.00 В`, статус `УПАЛ (>40°)`).
2. Активация баланса происходит автоматически только после установки корпуса строго вертикально (`|robot_angle| < 1.0°`).
3. При наклоне свыше `±40°` подача напряжения на обмотки мгновенно отключается, а интегральная ошибка сбрасывается.
